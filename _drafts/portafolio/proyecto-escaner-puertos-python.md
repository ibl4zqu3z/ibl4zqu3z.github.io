## Propósito

Proyecto propio diseñado para mostrar cómo construir un escáner de puertos en Python con una base clara, didáctica y suficientemente seria como pieza de portafolio.

## Qué demuestra

- Apertura de sockets y gestión de conexiones con control de errores.
- Uso de timeouts para evitar bloqueos innecesarios.
- Posibilidad de concurrencia básica para mejorar tiempos de ejecución.
- Presentación de resultados orientada a lectura rápida y utilidad práctica.

## Valor dentro del portafolio

No pretende competir con herramientas maduras. Su valor está en enseñar comprensión de fundamentos: cómo se modela un escaneo, cómo se estructuran resultados y cómo se transforma una idea simple en una utilidad reutilizable.

## Posibles extensiones

- Detección de banners.
- Exportación a JSON o CSV.
- Selección de rangos de puertos conocidos.
- Resolución DNS y enriquecimiento básico de resultados.
